## Реализованные части и пояснения

### 1. Разница между echo и print
- **echo** — конструкция языка для вывода данных. Может принимать несколько параметров, не возвращает значения.
- **print** — функция, возвращающая 1, работает как выражение, принимает только один параметр.

**Пример кода:**
```php
echo "Это сообщение выведено с помощью echo.";
print "Это сообщение выведено с помощью print.";
echo "Привет", " ", "мир!";
$printResult = print("print возвращает: ");
echo $printResult;
```
**Пример вывода:**
```
Это сообщение выведено с помощью echo.
Это сообщение выведено с помощью print.
Привет мир!
print возвращает: 1
```

### 2. Работа с переменными и выводом
- Создаются переменные разных типов.
- Демонстрируется вывод с помощью конкатенации (.) и интерполяции (двойные кавычки).

**Пример кода:**
```php
$days = 288;
$message = "Все возвращаются на работу!";
echo "В " . $days . " день, приблизительно ... " . $message;
echo "В $days день, приблизительно ... $message";
```

### 3. Арифметические операции
- Выполняются базовые арифметические действия: сложение, вычитание, умножение, деление, остаток от деления.

**Пример кода:**
```php
$a = 10;
$b = 5;
echo "Сложение: " . ($a + $b);
echo "Вычитание: " . ($a - $b);
echo "Умножение: " . ($a * $b);
echo "Деление: " . ($a / $b);
echo "Остаток от деления: " . ($a % $b);
```

### 4. Типы данных
- Создаются переменные разных типов: int, float, string, bool.
- Используется функция var_dump() для вывода типа и значения переменной.

**Пример кода:**
```php
$intVar = 42;
$floatVar = 3.14;
$stringVar = "Привет, PHP!";
$boolVar = true;
var_dump($intVar);
var_dump($floatVar);
var_dump($stringVar);
var_dump($boolVar);
```

### 5. Интеграция PHP и HTML
- PHP-код вставляется в HTML для динамического вывода данных (например, имени пользователя и текущей даты).

**Пример кода:**
```php
<h1>Добро пожаловать, <?php echo "гость"; ?>!</h1>
<p>Сегодня: <?php echo date("Y-m-d"); ?></p>
```

### 6. Вывод стиха
- Используется тег `<pre>` для сохранения форматирования.
- В тексте используются экранированные кавычки и переносы строк.

**Пример кода:**
```php
$poem = "\"Белеет парус одинокий\"\n    \"В тумане моря голубом!...\"\n    Что ищет он в стране далекой?\n    Что кинул он в краю родном?...";
echo '<pre>' . $poem . '</pre>';
```

**Пример кода:**
