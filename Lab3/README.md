# Лабораторная работа №3: Условные операторы и работа с датой в PHP

## Цель
Познакомиться с оператором if, тернарным оператором и оператором switch. Научиться анализировать работу условных конструкций и применять функции для обработки даты.

## Структура проекта
- `index.php` — основной файл лабораторной работы (задания 1, 2, 4, 5)
- `operator.php` — примеры условных операторов (задание 3)

## Как запустить
1. Убедитесь, что у вас установлен PHP (рекомендуется версия 7.0+).
2. Откройте терминал в папке с файлами лабораторной работы.
3. Запустите встроенный сервер командой:
   ```
   php -S localhost:8000
   ```
4. Откройте браузер и перейдите по адресу: [http://localhost:8000/](http://localhost:8000/)

## Описание заданий

### Задание 1
Выводит фамилию, имя и возраст клиента с помощью переменных и операторов вывода.

### Задание 2
Работа с условными конструкциями:
- if...else
- тернарный оператор
- elseif
- использование числового обозначения дня недели

### Задание 3 (`operator.php`)
Пример использования if, elseif и тернарного оператора для формирования сообщения в зависимости от возраста и имени.

### Задание 4
Использование оператора switch для определения текущего дня недели и вывода сообщения в формате:
```
Today is [weekday], [dd.mm.yyyy]
```

### Задание 5
Генерация HTML-таблицы с расписанием работы для двух сотрудников в зависимости от текущего дня недели.
